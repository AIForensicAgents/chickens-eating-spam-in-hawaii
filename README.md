# chickens-eating-spam-in-hawaii

A tiny, joyful collection of AI-generated images: chickens enjoying Spam in sunny Hawaii. This repo contains 10 whimsical images that blend island vibes, curious poultry, and a healthy dose of canned-meat nostalgia.

## Overview

This project showcases 10 AI-generated illustrations of chickens eating Spam in various Hawaiian settings — beaches, luaus, rainbows, and palm trees. Use these images for inspiration, placeholders, or to brighten up a README (with proper attribution if you remix or publish).

- Status: Completed
- Content: 10 images (AI-generated)
- Folder: /images

## Usage / Viewing

Viewing is easy — pick the method that fits:

- Preview on GitHub
  - Browse the images folder in this repository and click any image to view it in your browser.

- Clone and inspect locally
  - Clone the repo:
    ```
    git clone https://github.com/YOUR_USERNAME/chickens-eating-spam-in-hawaii.git
    cd chickens-eating-spam-in-hawaii
    ```
  - Open an image with your default image viewer, or view in a browser:
    ```
    open images/chicken-01.png  # macOS
    xdg-open images/chicken-01.png  # Linux
    start images\chicken-01.png  # Windows (PowerShell/CMD)
    ```

- Static file server (quick web preview)
  - Using Python 3:
    ```
    python -m http.server 8000
    ```
    Then visit http://localhost:8000/images/ in your browser.

- Download as ZIP
  - Use GitHub’s “Download ZIP” button on the main repo page.
